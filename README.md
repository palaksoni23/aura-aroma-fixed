# ☕ AURA & AROMA — Luxury Cafe Website

AURA & AROMA is a modern, elegant, and responsive website designed for a luxury cafe, bistro, and fine-dining restaurant. It features a premium visual experience with beautiful imagery, smooth animations, and a clean user interface.

🌐 **Live Demo:** https://aura-aroma-fixed.vercel.app

## ✨ Features

- **Premium Design:** Elegant and modern cafe-inspired UI.
- **Responsive Layout:** Designed to work across desktop, tablet, and mobile screens.
- **Hero Section:** Eye-catching landing section with high-quality visuals.
- **Menu Showcase:** Dedicated section to explore food and beverages.
- **Gallery:** Visual showcase of the cafe's ambience and dishes.
- **Reservation UI:** A reservation interface for visitors.
- **Smooth Animations:** Subtle transitions and interactive elements.
- **Custom Footer:** Includes project and developer information.

## 🛠️ Tech Stack

- React.js
- TypeScript
- Vite
- Tailwind CSS
- CSS Animations
- Vercel (Deployment)

## 🚀 Run Locally

Follow these steps to run the project on your computer.

**1. Clone the repository**

```bash
git clone https://github.com/palaksoni23/aura-aroma-fixed.git
```

**2. Navigate to the project folder**

```bash
cd aura-aroma-fixed
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the local URL**

Open the URL displayed in your terminal, usually:

```text
http://localhost:5173
```
